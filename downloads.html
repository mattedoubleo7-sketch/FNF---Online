Perseverance Source Layout

Perseverance now loads Dustin's 692 source chart events and uses the source ruins_exit coordinates for Sans, BF, GF, foreground, pillars, pixel Sans, the blaster, official snow layers, source-style camera follow, real camera-only character offsets, and the corrected post-pixel return. Sans and BF now stay on their source stage positions while Dustin's relative camera offsets affect only the camera target, singing poses use XML animation offsets, and Sans phase changes now follow the source character/suffix/forced-animation events.

Boxing Match WG now follows the Wii Funkin source zoom/stage setup, locks the impact/final landing camera to the scripted center, avoids full-canvas copies for smoke-only frames, and disables WG camera shader post-processing in Performance Mode.

Added a shared WebGL post-processing layer for camera shaders, wired Combat/One Hit/Shimmy chart events through it, and included the bridge in browser plus desktop build file lists.

Settings now has a Mobile toggle (4-lane on-screen buttons) and a Console toggle (Xbox / PlayStation / generic gamepads — D-pad and face buttons both map to the 4 lanes). Touch, keyboard, and gamepad all work simultaneously.

Quick Guide

Which one should friends use?

  • Best choice: send friends the hosted page and tell them to click Play Online In Browser.
  • Online: use this if friends are playing from different houses or different PCs.
  • Offline: use this if you just want local play with no server, or if two players are sharing one computer.
  • Mobile: open the browser version on a phone, then turn on Mobile in Settings — touch buttons appear for all 4 lanes.
  • Console: plug a controller in, turn on Console in Settings — D-pad and face buttons both fire the 4 lanes.
  • App: desktop apps are refreshed, but they are unsigned, so Windows may still show a warning.
  • JS: use this if you want the source files or want to self-host the build yourself.
